# 🎤 DevConf 2026 — Conference Website

একটি রেসপন্সিভ কনফারেন্স ওয়েবসাইট, যা তৈরি করা হয়েছে **HTML5** ও **CSS3** এর ফান্ডামেন্টালস ব্যবহার করে। এই প্রজেক্টে Flexbox ও Grid দিয়ে একটি মডার্ন লেআউট, সিমেন্টিক স্ট্রাকচার, ক্লিন UI ডিজাইন এবং ইউজার-ফ্রেন্ডলি ইন্টারফেস তৈরি করা হয়েছে। এটি "Assignment-01" এর অংশ হিসেবে তৈরি একটি বিগিনার-লেভেল প্রজেক্ট, যেখানে DevConf 2026 থিমের একটি সেকশন (যেমন Sponsors) ফোকাস করে ডিজাইন করা হয়েছে।

## 🛠️ ব্যবহৃত টেকনোলজি

- **HTML5** — সিমেন্টিক মার্কআপ ও স্ট্রাকচারের জন্য
- **CSS3** — স্টাইলিং, Flexbox ও Grid লেআউটের জন্য
- (যদি ব্যবহার করা হয়ে থাকে) **Google Fonts** — কাস্টম ফন্টের জন্য

## ✨ মেইন ফিচারসমূহ

- ফুললি রেসপন্সিভ ডিজাইন (মোবাইল, ট্যাব ও ডেস্কটপ ফ্রেন্ডলি)
- Flexbox ও CSS Grid দিয়ে তৈরি মডার্ন লেআউট
- ক্লিন ও সিমেন্টিক HTML স্ট্রাকচার
- Sponsors সেকশন (কনফারেন্সের স্পনসরদের প্রদর্শনের জন্য)
- ইউজার-ফ্রেন্ডলি ও visually attractive UI

## 📦 ডিপেন্ডেন্সি

এই প্রজেক্টে কোনো JavaScript ফ্রেমওয়ার্ক বা npm প্যাকেজ ব্যবহার করা হয়নি — এটি সম্পূর্ণ **plain HTML ও CSS** দিয়ে তৈরি। তাই আলাদা করে `npm install` করার প্রয়োজন নেই।

> যদি কোনো external CDN (যেমন Google Fonts, Font Awesome) ব্যবহার করা হয়ে থাকে, সেগুলোর লিংক এখানে যোগ করুন:
- [Google Fonts](https://fonts.google.com/)
- [Font Awesome](https://fontawesome.com/)

## 🚀 লোকাল মেশিনে রান করার গাইডলাইন

1. প্রজেক্টটি ক্লোন করুন:
   ```bash
   git clone https://github.com/abirhosen30/assignment-01.git
   ```
2. প্রজেক্ট ফোল্ডারে প্রবেশ করুন:
   ```bash
   cd assignment-01
   ```
3. `index.html` ফাইলটি সরাসরি ব্রাউজারে ওপেন করুন, অথবা VS Code এর **Live Server** এক্সটেনশন ব্যবহার করে রান করুন।
4. Live Server ব্যবহার করলে, `index.html` ফাইলে রাইট-ক্লিক করে **"Open with Live Server"** সিলেক্ট করুন।
