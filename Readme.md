এই প্রজেক্টে কোনো JavaScript ফ্রেমওয়ার্ক বা npm প্যাকেজ ব্যবহার করা হয়নি — এটি সম্পূর্ণ plain HTML ও CSS দিয়ে তৈরি। তাই আলাদা করে npm install করার প্রয়োজন নেই।

🚀 লোকাল মেশিনে রান করার গাইডলাইন
প্রজেক্টটি ক্লোন করুন:
bash
   git clone https://github.com/abirhosen30/assignment-01.git
প্রজেক্ট ফোল্ডারে প্রবেশ করুন:
bash
   cd assignment-01
index.html ফাইলটি সরাসরি ব্রাউজারে ওপেন করুন, অথবা VS Code এর Live Server এক্সটেনশন ব্যবহার করে রান করুন।
Live Server ব্যবহার করলে, index.html ফাইলে রাইট-ক্লিক করে "Open with Live Server" সিলেক্ট করুন।
